## 📬 FormSubmit AJAX Integration & Activation

The contact system uses FormSubmit's AJAX endpoint (`POST https://formsubmit.co/ajax/askfor.amithalder@gmail.com`) with JSON body:

- **Fields**: `name`, `email`, `subject`, `message`
- **Configuration**:
  - `_subject`: `"New Portfolio Inquiry — Amit Halder"`
  - `_replyto`: Visitor's email address
  - `_template`: `"table"`
  - `_url`: Originating page URL
  - `_captcha`: `"false"`
- **Validation**: Client-side inline error alerts for empty fields and email regex validation.
- **States**: Real-time loading indicator ("Sending..."), success banner with animated checkmark and `aria-live="polite"`, and graceful error handling that preserves visitor input.

> [!IMPORTANT]
> **One-Time Email Activation**:
> FormSubmit requires a one-time activation for new destination email addresses. When the first inquiry is submitted, FormSubmit sends an activation link to `askfor.amithalder@gmail.com`. Once the owner clicks "Activate Form", all subsequent inquiries are delivered directly to the inbox without redirection.

## 💻 Local Development Setup

### Prerequisites

- Node.js 18+ (tested on Node v24.20.0)
- npm 9+ (tested on npm 11.19.0)

### Installation

```bash
# Clone the repository
git clone https://github.com/Martish-cloud/Amit-Halder-Data-Entry-Executive-.git

# Navigate into the project folder
cd Amit-Halder-Data-Entry-Executive-

# Install dependencies
npm install
```

### Running Locally

```bash
npm run dev
```

Visit `http://localhost:5173` in your browser.

## 🏗️ Build & Production

```bash
# Type check and build production bundle
npm run build

# Preview production bundle locally
npm run preview

# Run linting check
npm run lint
```

Production output is compiled into the `dist/` directory with relative asset paths for universal hosting compatibility.
